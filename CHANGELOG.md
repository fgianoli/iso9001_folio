# Cambiamenti

## 0.2.0
- Interfaccia in italiano e inglese (Personalizza → Aspetto → Lingua, o scelta al primo avvio): testi, messaggi, README delle cartelle, procedura documentata, registro eventi e modelli di partenza.
- Riscrittura in Rust con interfaccia Tauri: un'app installabile per Windows, macOS e Linux, senza Python.
- Personalizzazione: nome, colori, tema, carattere, vocabolario, nomenclature a modello, tipi di progetto con sottocartelle e modelli, stati, colonne del registro, regole di pulizia; modelli di partenza e profili esportabili.
- Controlli ISO 9001: responsabile, riesame dei requisiti, revisioni, approvazione prima della chiusura, non conformità con azioni correttive, conservazione, registro cronologico, procedura documentata.
- Migrazione automatica dalla configurazione della versione Python.
